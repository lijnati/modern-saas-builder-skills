# Modern SaaS Builder Assets

This directory contains bundled assets, boilerplate templates, reusable schemas, and configuration blueprints used by the `modern-saas-builder` skill.

## Asset Contents

- **`templates/`**: Starter templates for Next.js modular monoliths, Prisma schemas, and Dockerfiles.
- **`schemas/`**: Reference JSON and Zod validation schemas for billing events, agent policies, and Telegram webhooks.
- **`configs/`**: Recommended ESLint, Prettier, Tailwind, and TypeScript configuration presets.
