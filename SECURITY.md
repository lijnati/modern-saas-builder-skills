# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a vulnerability or security flaw in the CLI, templates, or scripts:

1. **Do not create a public GitHub issue.**
2. Please report your findings via private GitHub Security Advisory or email the repository maintainers directly.
3. Provide as much detail as possible:
   - Description of the issue
   - Reproduction steps or proof-of-concept
   - Potential impact
4. We aim to acknowledge receipt of vulnerability reports within 48 hours and provide a fix or mitigation plan within 7 days.
