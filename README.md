# Modern SaaS Builder Skills

A reusable skill for planning, building, validating, securing, deploying, and growing modern SaaS products.

## Contents

- `SKILL.md`: Core instructions and operating modes.
- `references/`: Guidance for architecture, UX, testing, security, growth, and related product areas.
- `scripts/`: Project health, security, and verification checks.

## Verification

Run the scripts from the repository root:

```bash
bash scripts/verify.sh
bash scripts/project-health.sh
bash scripts/security-check.sh
```
